# ESG — Values

Domain edge attributes with quantitative/temporal data materialize as `value` records.

| Edge type | Attributes → values |
|-----------|---------------------|
| REQUIRES_DISCLOSURE | mandatory, phase_in_year |
| CONTAINS_METRIC | datapoint_id, quantitative |
| REFERENCES_STANDARD | reference_type, binding |
| MEASURED_FROM | calculation_method, coverage_pct, quality_assessment |
| ADDRESSES_TOPIC | coverage_level |
| MITIGATES | residual_risk_level, control_type |
| APPLIES_TO | eligibility_status, assessment_year |
| ASSESSED_FOR | assessment_date, score, method |
| REPORTED_IN | value, period, assured, page_reference |
| OWNS | responsibility_type, data_quality_score |
| TRACKS_TARGET | measurement_method |
| RAISED_ON | finding_type |
| MATERIAL_FOR | determines_disclosure |
| SUPPLIES_TO | supply_category, criticality |
| HAS_SUBREGULATION | relationship |
